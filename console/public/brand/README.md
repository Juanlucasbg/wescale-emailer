WeScale brand assets

Source: https://wescale.ai/ (retrieved September 30, 2026).
The wordmark, founders photo, resource artwork, and Poppins font files are served locally. Compact icons use the W from the official wordmark. White wordmark is a monochrome derivative for dark surfaces.

Poppins is distributed under the SIL Open Font License; its copyright notice and license are included in `fonts/OFL.txt`. Source: https://github.com/google/fonts/tree/main/ofl/poppins.

Website palette: #ffffff (white), #f5f5f4 (soft), #e7e7e4 (border), #111114 (ink), #52525a (secondary), #86868e (muted), #0f8a3d (green), #dff1e5 (green tint), #47d616 (CTA), #27770b (CTA hover).
Primary controls use dark text on the bright CTA for readability; text links use the darker green.
